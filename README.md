# Foodies - Modern Recipe & Food Blog Application

A responsive and interactive web application built as part of the **Web Technologies** course at **Leading University**. This project focuses on modern frontend development practices, clean UI/UX, and interactive user feedback.

## 🚀 Project Overview
Foodies is a platform where users can explore various food categories, read detailed recipe blogs, and interact through a modern interface. It serves as a practical implementation of utility-first CSS and component-based architecture.

## 🛠️ Tech Stack
- **Styling:** Tailwind CSS (Responsive Design)
- **Icons:** Lucide React / FontAwesome
- **Interactivity:** SweetAlert2 (Draggable Alerts)
- **Language:** JavaScript (Vanila)

## ✨ Key Features
- **Responsive Layout:** Optimized for Mobile, Tablet, and Desktop using Tailwind's `md:` and `lg:` breakpoints.
- **Interactive Alerts:** Custom-styled draggable success alerts using **SweetAlert2**.
- **Modern UI Components:**
  - **Hero Section:** Dynamic floating imagery and clear Call-to-Action.
  - **Category Filter:** Visual categorization for easy navigation (Breakfast, Vegan, Meat, etc.).
  - **Newsletter:** Seamless subscription interface with smooth background blending.
- **Visual Polish:** Implementation of `flex-wrap`, `overflow-hidden`, and custom `line-height` for superior readability.
